# Workflow examples

These files are educational structures only. They do not contain bundled weights, production class names, production thresholds, or existing workflows. Importing an example does not make it runnable: first register compatible local models, then review every node parameter and validate on non-sensitive test media.

`associate-crop-infer.json` mirrors the generic VideoPipe-style pattern of source → parallel inference → relationship rule → crop → downstream inference → visualization.
